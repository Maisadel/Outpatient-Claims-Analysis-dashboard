# 🏥 Outpatient Claims Analysis & Healthcare Intelligence Dashboard

## 📊 Project Overview
This project focuses on analyzing outpatient healthcare claims to uncover key insights into patient treatments, diagnosis distributions, provider performance, and total insurance reimbursements. The end-to-end workflow bridges data extraction using **SQL Server Management Studio (SSMS)** with interactive visualization in **Power BI**.

---

## 🛠️ Tools & Technologies Used
* **SQL Server Management Studio (SSMS):** Used for querying, data cleaning, and aggregating claims datasets.
* **Power BI Desktop:** Used for building an interactive analytics dashboard with optimized visual hierarchy.

---

## 📈 Key Dashboard Visuals & Metrics
1. **Total Reimbursed Amount:** Card visual displaying the overall financial reimbursement volume (`147.91M+`).
2. **Top Providers by Claims:** Clustered column chart highlighting high-volume healthcare providers.
3. **Claims Distribution by Diagnosis Code:** Analyzes patient volume across various admitting diagnoses to track prevalent medical conditions.

---

## 📁 Repository Structure
* `Outpatient_Claims_Analysis.pbix`: The interactive Power BI dashboard file.
* `Healthcare_Analysis_Queries.sql`: The complete SQL script used for data extraction and aggregation.
